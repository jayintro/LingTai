# LingTai 

> 通用工具启动引擎 —— 一站式管理 JAR / EXE / PY / Ftools 工具

LingTai 是一个轻量级桌面应用平台，当前仅具备工具箱模块，该模块专为需要频繁启动各类开发与安全工具的场景设计。支持 Java JAR、Windows EXE、Python 脚本的统一管理与一键启动，并为 Python 工具提供**虚拟环境隔离**与**依赖自动管理**。

## ✨ 特性

### 多类型工具管理

|类型|图标|说明|
|---|---|---|
|☕ JAR|绑定 JDK 版本，支持自定义 JVM 参数||
|⚙️ EXE|支持 GUI / 命令行两种子类型||
|🐍 PY|绑定 Python 版本，自动创建虚拟环境隔离依赖||
|📂 Ftools|快捷目录入口，点击即打开工作目录||

### Python 依赖自动管理

- **启动时预检**：首次启动自动扫描工具目录下所有 `.py` 文件的 import 语句，在虚拟环境中批量检查可导入性，缺失的依赖自动补装

### 安全与健壮性

- **虚拟环境隔离**：每个 PY 工具独立 `.venv`，互不干扰
- **参数注入防护**：JVM 参数和 bat 脚本参数均做安全转义，防止命令注入
- **进程安全管控**：退出时自动终止子进程，支持强制终止无响应进程
- **原子写入**：配置文件写入使用临时文件+替换，防止数据损坏

### 其他

- 🔍 实时搜索：按名称、分类、备注、类型、运行时过滤（支持 Ctrl+F 快捷键）
- 📂 分类管理：左侧分类栏，支持新建 / 重命名
- 📋 运行日志：每个工具独立日志文件，支持查看与清理

## 🚀 快速开始

### 环境要求

- **Windows 10/11**（目前仅支持 Windows）
- **Python 3.10+**（运行源码）
- **Java JDK**（如需启动 JAR 工具）

### 源码运行

```bash
# 克隆仓库
git clone https://github.com/your-username/LingTai.git
cd LingTai

# 运行（无需安装额外依赖，仅使用 Python 标准库）
python main.py
```
## 📖 使用指南

### 1. 配置运行环境

首次使用前，先配置 JDK 和 Python 运行时：

1. 菜单栏 → **设置** → **运行环境（JDK / Python）**
2. 添加 JDK：填写名称、版本号、`java.exe` 路径
3. 添加 Python：填写名称、版本号、`python.exe` 路径

### 2. 添加工具

1. 点击 **+ 添加工具**
2. 选择工具类型（JAR / EXE / PY / Ftools）
3. 填写工具信息：
    - **名称**：工具的显示名称
    - **文件路径**：JAR / EXE / PY 文件位置（Ftools 类型留空）
    - **工作目录**：运行时的工作目录（留空自动取文件所在目录）
    - **运行时绑定**：JAR 绑定 JDK，PY 绑定 Python，EXE需要确定类型（GUI工具/命令行工具）
    - **启动参数**：程序运行参数（可选）
    - **JVM 参数**：JAR 专用，如 `-Xmx2g`（可选）
    - **备注**：工具说明（可选）
4. 选择分类 → 保存

### 3. 启动 / 停止工具

- **启动**：双击工具行，或右键 → ▶ 启动
- **停止**：右键 → ■ 停止
- **强制终止**：右键 → ⚡ 强制终止（用于无响应的进程），或直接关闭工具窗口（蚁剑类的工具需要在右下角关闭后台运行）
- **搜索**：Ctrl+F 聚焦搜索栏，Enter 启动**首条**匹配结果，ESC退出搜索

### 4. Python 工具依赖管理

PY 工具默认启用虚拟环境隔离（`use_venv`），启动流程：

1. **首次启动**：自动创建 `.venv` → 扫描 import → 预装缺失依赖
2. **后续启动**：跳过初始化，直接运行
3. **运行时崩溃**：如果因缺失依赖退出，弹窗提示 → 一键补装 → 自动重启

依赖映射表位于 `data/module_map.json`，可根据需要添加自定义映射。

### 5. 日志管理

- 点击 **📋 日志** 查看当前工具的运行日志
- 菜单栏 → **日志** → 清理 7 天前日志 / 清理全部日志

## 🔧 配置文件

|文件|说明|是否跟踪|
|---|---|---|
|`data/module_map.json`|Python 模块→包名映射表|✅ 是|
|`data/tools.json`|工具列表|❌ 否（用户数据）|
|`data/jdks.json`|JDK 配置|❌ 否（用户数据）|
|`data/pythons.json`|Python 配置|❌ 否（用户数据）|
|`data/categories.json`|分类列表|❌ 否（用户数据）|
